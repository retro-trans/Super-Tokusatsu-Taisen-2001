# Title-screen credit and build version

Every build displays two small right-aligned lines on the title artwork: `v<build version>` and `github.com/retro-trans`, following `../SRW Z3/docs/TITLE_FOOTER.md`. The normal builder passes its version argument directly to `tools/title_footer.py`; the same value identifies the disc filename and build report. The permanent rule is recorded in AGENTS.md.

The builder reads both title-art copies back from the completed disc before reporting success. A missing or stale version fails the build. Restamping clears the previous footer from the original artwork first, so changed digit widths cannot leave old pixels behind.

Both copies of the 320x240 title artwork are stamped: MAPMAIN entry 19 and entry 23's compressed block 0. All pixels outside native rectangle (188,208)-(312,234), TIM headers, CLUTs, trailing padding, the separate menu block and copyright texture remain intact. It is native disc artwork and works without emulator texture replacement.

From v0.3.20, the footer uses original pixel lettering baked into the title image, with pure white strokes on solid dark backing. The former tiny outlined font was difficult to read against the artwork. `work/ui/title/footer_font.en.json` defines every glyph as fixed bitmap rows; installed system fonts and emulator texture hashes cannot alter it. The URL occupies (203,221)-(310,232) and the version uses nine-pixel-high ink ending at y=219. Two pixels of dark padding separate the strokes from the busy background; the backing begins at x=201, clear of the centered menu. Automatic version generation and disc readback verification remain in place. Historical v0.3.19 rebuilds keep their original 9px GenEi LateGo outlined lettering.

Preview and dry run: `C:/Python/python.exe tools/title_footer.py 0.3.20`; add `--write` to export native-resolution and 3x asset previews and English layout metadata in `work/ui/title/`. These exported images are artwork previews, not screenshots. `tools/build.py 0.3.20 --keep-font --movies --dry-run` validates the footer and previews the build options without writing a game image. The build's `title_footer` report records both copies and their exact labels, ink bounds and backing bounds.

`tools/check_title_footer.py <version> <baseline> --verify` reads the completed disc and verifies the title edits, exact version, layout bounds, preserved metadata, untouched menu/archive contents, all other game files, raw movie sectors and all font-package files. It also confirms that changing the version changes the title pixels. `tools/check_public_build.py` includes the footer for v0.3.19 and later so the stripped public source can reproduce it.

v0.3.19 and v0.3.20 are local test builds, not GitHub releases. The matching texture package is regenerated by the normal builder; its font images and settings remain compatible with v0.3.18 because these changes edit only title artwork.
