# v0.9.7 publication

Published 2026-11-19: https://github.com/retro-trans/Super-Tokusatsu-Taisen-2001/releases/tag/v0.9.7.

The release uses the exact tested local v0.9.7 image;
target SHA-256 `110ab27fcbb9de6b5dc991e7f6ad2dd25291733f516814ef044951bcdacf92ae`,
725,316,816 bytes. Do not rebuild or alter the game to package this release.

Publish exactly two bare patches: original Japanese SLPS-02863 -> v0.9.7,
and previous public v0.9.1 -> v0.9.7. The original and previous source hashes
must match the public Retro Trans Tools catalog. Local v0.9.2–v0.9.6 upgrade
routes remain local and are not release attachments.

Cumulative changes since v0.9.1: restore Henshin; flat native ink and dark
shadows with aligned Latin metrics; English startup copyright; new Luciferd
and EATER title graphics; generated narration and lettering for all 90
episode cards; 15 verified Latin staff-name readings in both ending movies.
Fourteen personal names remain Japanese pending verified readings.

The font and graphics are native and require no texture replacement. The
release instructions also require a matching optional texture package;
v0.9.7 supplies 1,058 exact-native images with unchanged sampled palettes,
ink, shadows and icon colours. It does not redraw glyphs or provide extra
detail beyond the current native font. No pack is installed or enabled by
this release workflow. Its 72,351,744 sampled palette pixels and native
upload IDs are checked.

All nine font/rendering/runtime issue checks pass on the completed image:
glyph baselines/heights, shadow colour cases, load delays, native packet
bounds, saved names and checksums, dialogue clearing, difficulty modes,
upgrade prices/purchases and rewards, Evade/Defend, Max Lv. and Stats rows.
The reference test tools were updated for the new title-wordmark manifest
and the current native-compatible font drawer. No game bytes change during
those test-tool updates. The English-only source rebuild passes.

Movie audit compares directly with public v0.9.1. Only clips 31, 34, 71 and
72 differ; all 28 inserted streams decode, all original XA audio and movie
allocations remain intact, and 95,785 movie/native sectors pass EDC/ECC.
Native archive relocation is audited separately by exact source rebuilding,
font/geometry checks and the v0.9.6-to-v0.9.7 raw-disc artwork comparison.
The opening stream is byte-identical to the approved v0.9.0 stream, allowing
reuse of its complete timing, crop and audio review. This does not claim
native archives remain byte-identical to public v0.9.1.

Both completed title copies verify v0.9.7 and github.com/retro-trans. Release
notes and README follow SRW-Z's layout, credit pow as project lead and
Karnik as playtester, and explain native and optional texture installation.
Full campaign, emulator/PSP playback and the outstanding encyclopedia
reports remain unverified. No complete game image is distributed.
